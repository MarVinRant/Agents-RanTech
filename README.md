# RanTech Agentes Platform V1

Estrutura visual inicial da plataforma multiempresa RanTech Agentes. Usa mocks e prepara o futuro RanTech Admin e Portal do Cliente.

## Rodar

npm install
npm run dev

Abra http://localhost:3000.

## Estado atual

AppShell responsivo com sidebar recolhível, header, organização atual, notificações e perfil. Dashboard com métricas, gráfico, atividade recente e organizações em destaque. A navegação está preparada para os módulos do produto.

Nenhuma API, autenticação, Supabase, n8n, WhatsApp, OpenAI ou credencial foi conectada.

## Direção visual

Azul profundo, azul de ação e ciano como acento, com tipografia de interface limpa. Os tokens estão em app/globals.css. A identidade oficial deve substituir esses tokens quando os arquivos de marca forem adicionados.
